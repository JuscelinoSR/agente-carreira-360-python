# Como contribuir

Obrigado pelo interesse em melhorar este projeto.

## Sugestões e problemas

Abra uma issue com uma descrição clara, resultado esperado e, quando aplicável, passos para reproduzir. Use dados fictícios em exemplos e capturas de tela.

## Enviar uma alteração

1. Faça um fork e crie uma branch descritiva, como `docs/instrucoes-uso` ou `fix/validacao-dados`.
2. Faça uma alteração pequena, mantendo o estilo e a estrutura existentes.
3. Confira os links e exemplos da documentação. Para mudanças de código, execute o fluxo afetado e registre o resultado.
4. Use uma mensagem de commit que descreva a mudança.
5. Abra um pull request explicando o problema, a solução e como foi validada.

## Convenções do projeto

Prefira Python puro, funções pequenas, `pathlib` e `json`. Não adicione dependências sem discutir a necessidade. Materiais de carreira devem ser rascunhos para revisão humana. Não invente experiências profissionais nem automatize publicações.

## Convivência e dados

Mantenha uma comunicação respeitosa. Não inclua senhas, tokens, dados de clientes ou documentos pessoais. Consulte [CODE_OF_CONDUCT.md](CODE_OF_CONDUCT.md).
